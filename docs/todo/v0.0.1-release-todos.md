## better-auth plugins (MEDIUM — opt-in, by need)

> better-auth 1.7.0-rc 加入的企業級功能，視產品需求按需啟用（`gstack add auth-plugin`）

- [ ] **DPoP** — RFC 9449 Proof-of-Possession，綁定 access token 到特定金鑰，防 token replay。適合高安全場景（金融、內部 API）
- [ ] **SCIM** — 企業使用者生命週期管理（SSO user provisioning）。適合 B2B SaaS（Okta/Entra ID 同步）
- [ ] **Back-channel logout** — OIDC Back-Channel Logout (RFC 8894)，登出事件廣播到各依賴方。適合多應用單一登出
- [ ] **Passkey** — WebAuthn 支援（1.7 也在推進）
- [ ] **twoFactor** — TOTP 雙因子驗證
