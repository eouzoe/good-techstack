good-techstack 是一套 Cloudflare 原生的 TypeScript 範本：以 Bun 作為執行環境與工具鏈、Cloudflare Workers 搭配 D1、oRPC 契約、better-auth 身分驗證、TanStack Start 前端，外加可重現的 devenv 工具鏈。

本站台渲染的 Markdown 就存放在倉庫的 `docs/src/content/docs/zh-Hant/` 底下；你可以在此閱讀，也可以回到原始碼閱讀、修改、發佈。

先從 [指南](/zh-hant/guide/) 開始，再讀 [參考文件](/zh-hant/reference/)（分層契約與測試矩陣）、[Agent 文件](/zh-hant/agent/)（啟動提示與行為規則），或看 [待辦](/zh-hant/todo/)。
