good-techstack is a Cloudflare-native TypeScript template: Bun for runtime and tooling, Cloudflare Workers with D1, oRPC contracts, better-auth, TanStack Start for the frontend, and a reproducible devenv toolchain.

Start with [Getting started](/en/getting-started/), then browse the [Guide](/en/guide/) for task walkthroughs, the [Reference](/en/reference/) for per-layer contracts and the test matrix, or the [Agent](/en/agent/) docs for the bootstrap prompt and behaviour rules.
